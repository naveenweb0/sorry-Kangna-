# For Kangna 🌸

An interactive, sincere personal letter and appreciation web experience. Crafted with warm aesthetics, delicate micro-interactions, ambient soundscapes, and thoughtful motion design.

## Features

- 💌 **Interactive Letter & Envelope** — Smooth 3D tilt and unfolding envelope with heartfelt handwriting presentation.
- 🌷 **Blooming Blossom Experience** — Interactive procedural flower animations with delicate petal blooms.
- 🎵 **Ethereal Ambient Audio** — Gentle pentatonic chimes with custom synthesized web-audio reverb for an emotional atmosphere.
- 🌸 **Drifting Petals & Stardust** — Organic particle physics and floating ambient petals.
- 🕊️ **Reflections & Appreciation Notes** — Playfully tilted sticky notes with interactive reactions, confetti micro-delights, and personal commitments.
- 💫 **Peace Treaty & Mood Check** — Zero-pressure, warm interactive check-in giving full respect and space.
- 📱 **Fully Responsive & Accessible** — Fluid typography, dark/light harmonic palette, keyboard navigability, and `prefers-reduced-motion` compliance.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **UI & Animations**: [React 19](https://react.dev), [Framer Motion](https://www.framer.com/motion/), [Tailwind CSS v4](https://tailwindcss.com)
- **Icons**: [Lucide React](https://lucide.dev)
- **Typography**: Playfair Display, DM Sans, Caveat
- **Testing**: [Vitest](https://vitest.dev) & Testing Library

## Getting Started

### Prerequisites

- Node.js 20+
- npm (or pnpm / bun)

### Installation

```sh
npm install
```

### Development Server

Run the development server locally:

```sh
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) in your browser.

### Production Build

```sh
npm run build
npm run preview
```

### Running Tests

```sh
npm test
```
